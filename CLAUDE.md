## Overview

A web-based tool that generates 3D Gazebo simulation worlds from real-world elevation data and satellite imagery. Users select a geographic region in the browser, and the tool downloads tiles from Mapbox, generates heightmaps and orthoimagery, optionally adds 3D buildings from OpenStreetMap, and writes complete Gazebo world/model files (SDF format).

## Setup & Running

```bash
pip install -r requirements.txt
python scripts/server.py
```

The server starts at `http://localhost:8080`. A valid Mapbox API key is required — set `MAPBOX_KEY` env variable or enter it in the UI.

**Environment variables:**
- `MAPBOX_KEY` — Mapbox API key
- `GAZEBO_MODEL_PATH` — output directory for model files (default: `~/.gazebo/models/`)
- `GAZEBO_WORLD_PATH` — output directory for world files (default: `~/gazebo_worlds/`)

No build system, test framework, or linter is configured.

## Architecture

### Request Flow

```
Browser UI → Flask API (server.py)
  /start-download  → writes metadata JSON
  /download-tile   → receives and stitches satellite tiles
  /end-download    → spawns background thread → full world generation
  /task-status     → polls generation progress
```

### Class Hierarchy

`GazeboTerrianGenerator` (gazeboWorldGenerator.py) inherits from both:
- `HeightmapGenerator` (heightMapGenerator.py) — converts DEM tiles into a grayscale heightmap PNG
- `OrthoGenerator` (gazeboWorldGenerator.py inner class) — stitches satellite tiles into orthoimagery

`GazeboTerrianGenerator.generate_gazebo_world()` is the main orchestration entry point called from `server.py`.

### Key Modules

| Module | Responsibility |
|--------|---------------|
| `server.py` | Flask app, REST endpoints, threading |
| `gazeboWorldGenerator.py` | Top-level orchestration, ortho stitching, SDF/world/config file generation |
| `heightMapGenerator.py` | DEM tile → heightmap PNG conversion |
| `demTilesDownloader.py` | Parallel download of Mapbox Terrain DEM v1 tiles |
| `buildingDownloader.py` | Mapbox vector tile download + protobuf decode → GeoJSON |
| `buildingsGenerator.py` | GeoJSON building footprints → DAE 3D mesh models |
| `fileWriter.py` | Thread-safe writing of SDF, config, metadata JSON using templates |
| `maptileUtils.py` | Lat/lon ↔ Web Mercator tile coordinate math (wraps `mercantile`) |
| `param.py` | Global constants: paths, resolution settings, API keys |

### Templates

SDF/world/config files are generated by string substitution from:
- `templates/gazebo_world.txt` — world SDF
- `templates/sdf_temp.txt` — model SDF
- `templates/config_temp.txt` — model config

### Coordinate System Notes

- Tile coordinates use Web Mercator (EPSG:3857)
- `maptileUtils` converts between lat/lon (WGS84) and tile x/y/z
- Heightmap pixel bounds are calculated relative to the selected bounding box corners
- World dimensions passed to Gazebo are in meters, derived from geodetic calculations via `geopy.distance`
